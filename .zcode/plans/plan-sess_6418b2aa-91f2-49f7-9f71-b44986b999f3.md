# Toggleable "Max agent steps per turn" (default: unlimited)

## Background
The step limit is `maxSteps` on `LlmSettings` (default 100), enforced entirely client-side in the browser agent loop (`runRealTurn` in `src/agent/agentLoop.ts`), persisted in localStorage (`mrs.settings`, spread over `DEFAULT_LLM_SETTINGS` in `loadSettings()` — new boolean fields get their default automatically, no migration needed). The chat shows "step i/max" while running (`ChatPanel.tsx:313`).

## Changes

### 1. `src/agent/types.ts` — new setting
- Add `limitMaxSteps: boolean;` to the `LlmSettings` interface (next to `maxSteps`, line 94).
- Add `limitMaxSteps: false` to `DEFAULT_LLM_SETTINGS` — **unlimited is the default**.

### 2. `src/agent/agentLoop.ts` — enforce conditionally
- Line 128: pass the effective limit instead of the raw value:
  ```ts
  await runRealTurn(taskId, rt, store.settings.model,
    store.settings.limitMaxSteps ? store.settings.maxSteps : Number.POSITIVE_INFINITY,
    rt.abort.signal);
  ```
- `runRealTurn` needs no other change: `for (let step = 1; step <= maxSteps; step++)` runs indefinitely with `Infinity` until the model stops calling tools or the user aborts; the exhaustion notice ("Step limit reached") becomes unreachable in unlimited mode, and the `step >= maxSteps` counter reset (line 421) never fires (it's cosmetic-only — the counter is reset per turn and only displayed while running).

### 3. `src/ui/ChatPanel.tsx:313` — step display
- Unlimited → show only the current step; limited → keep "step i/max":
  ```tsx
  {agentStep > 0
    ? `· ${settings.limitMaxSteps
        ? t("chat.stepOf", { i: agentStep, max: settings.maxSteps })
        : t("chat.step", { i: agentStep })}`
    : ""}
  ```

### 4. `src/ui/SettingsDialog.tsx` — toggle UI
- New state: `const [limitMaxSteps, setLimitMaxSteps] = useState(settings.limitMaxSteps);`
- `apply()` (line 121) and `test()` (line 129) objects gain `limitMaxSteps` (the `test()` literal must include it to satisfy the `LlmSettings` type).
- Rework the maxSteps field (lines 205-208): the label row becomes a checkbox + "Max agent steps per turn" label; the number input gets `disabled={!limitMaxSteps}` so the value stays visible but greyed out when unlimited (uses the existing `input[type=checkbox]` styling from `styles.css:251`, same pattern as `Inspector.tsx:154`); add a hint explaining the default.

### 5. `src/i18n/en.ts` + `src/i18n/zh.ts`
- `"chat.step": "step {i}"` / `"chat.step": "第 {i} 步"`
- `"settings.maxStepsHint"`: EN "Unchecked (default): the agent may take as many steps as it needs. Checked: the turn pauses after this many steps — send a message to continue." / ZH "未勾选（默认）：智能体步数不受限制。勾选后：每轮达到该步数即暂停——发送消息可继续。"
